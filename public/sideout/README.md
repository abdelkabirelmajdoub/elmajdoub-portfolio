# Sideout

Volleyball match finder frontend by Abdelkabir El Majdoub.

Live demo: https://sideout-silk-iota.vercel.app/

Built with HTML, CSS, and JavaScript. Features court and skill-level filters, local demo reservations, keyboard focus styles, live feedback, and responsive layouts.

All matches are illustrative; no real bookings or backend are included.

Open index.html directly or serve this directory with a static HTTP server. This directory is also copied unchanged by the portfolio's Vite build.
